# Third-party font licenses

The storefront self-hosts the following font families through pinned Fontsource packages. The font files are bundled with the application; the production build does not fetch fonts from Google at build time or the browser at runtime.

| Family | Package | Version | License | Attribution |
|---|---|---:|---|---|
| Cormorant Garamond | @fontsource-variable/cormorant-garamond | 5.3.0 | SIL Open Font License 1.1 | Copyright 2015 The Cormorant Project Authors |
| DM Sans | @fontsource-variable/dm-sans | 5.3.0 | SIL Open Font License 1.1 | Copyright 2014 The DM Sans Project Authors |

Upstream font source: [Google Fonts](https://github.com/google/fonts). Fontsource package metadata and license files are distributed with the installed npm packages. The font files are used under their OFL-1.1 terms; no font modifications are made by this project.

The complete OFL text and any reserved-font-name terms must remain with redistributed font files in accordance with each package's included license.
